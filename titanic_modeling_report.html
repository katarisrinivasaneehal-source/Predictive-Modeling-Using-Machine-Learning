🎯 Predictive Modeling: Titanic Survival

Training and comparing supervised learning models to predict passenger survival

1. Setup

  • Dataset: the cleaned Titanic dataset (891 passengers, 0 missing values) from the previous cleaning project.
  • Target: Survived (0 = died, 1 = survived) — a binary classification problem.
  • Features used: Pclass, Sex, Age, SibSp, Parch, Fare, Embarked, HasCabin, FamilySize, IsAlone.
  • Split: 80% training / 20% testing, stratified to preserve the survival ratio in both sets.
  • Note on algorithm choice: the brief mentions "Linear Regression," but since the target here is a category (survived / died) rather than a continuous number, Logistic Regression is the correct classification counterpart — it's used the same way Linear Regression would be for a numeric target, just adapted for a yes/no outcome.

Best model: Logistic Regression

Logistic Regression performed best here — a common result on datasets like this where relationships between features (class, sex, fare) and the outcome are fairly linear/additive. Decision Tree and Random Forest are more powerful for complex, non-linear patterns, but on a dataset this size and this clean, the simpler model generalizes better and avoids overfitting.

5. What Drives the Predictions?

Key takeaways:
  • Sex and Fare/Pclass are consistently the strongest predictors — confirming the "women and children first, and wealthier passengers had better odds" pattern seen in the earlier exploratory analysis.
  • Age matters, but less than class and sex.
  • Family-related features (FamilySize, IsAlone) have moderate influence — supporting the earlier finding that small families survived better than solo travelers.

6. Evaluation Metrics Explained

  • Accuracy — % of all predictions that were correct.
  • Precision — of everyone predicted to survive, what % actually did.
  • Recall — of everyone who actually survived, what % the model correctly caught.
  • F1 Score — balance between precision and recall.
  • AUC (Area Under ROC Curve) — how well the model separates the two classes overall; 1.0 is perfect, 0.5 is random guessing. All three models score well above 0.5, confirming real predictive power.
